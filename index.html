① 사진 또는 상품 링크 가져오기

사진은 여러 장 첨부할 수 있습니다. 상품 링크는 상품 페이지를 열어 참고할 수 있으며, 직접 이미지 주소인 경우 불러오기를 시도합니다.

상품 페이지는 보안 정책(CORS) 때문에 사진을 자동으로 가져오지 못하는 쇼핑몰이 많습니다. 직접 이미지 주소는 허용된 경우에만 불러올 수 있습니다. 상품 페이지는 새 탭으로 열어 사진을 직접 저장한 뒤 첨부해 주세요.

② 분석할 사진 선택

분석에 사용할 사진을 선택하세요. 여러 장을 선택한 뒤 각각 다른 옷을 분석할 수도 있습니다.

③ 분석할 옷 영역 지정

사진 속 여러 상품 중 분석할 옷 부분을 손가락이나 마우스로 드래그해 사각형으로 지정하세요. 선택한 영역 안의 픽셀 색상을 분석합니다.

사진 위에서 원하는 옷을 둘러싸도록 드래그하세요. 선택 영역을 다시 그리면 이전 영역이 교체됩니다.
아직 분석 영역을 지정하지 않았습니다.
